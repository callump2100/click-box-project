# Click Box Project

A simple interactive JavaScript project where a button changes the color and text of a box when you click, hover, or move your mouse away.

## Features
- Click the button to change the box to a cold theme ❄️
- Hover over the button to show a “kinda cold” message 😰
- Move your mouse away to reset the box 😃

## Files
- **index.html** — main structure of the page  
- **style.css** — styling and layout  
- **script.js** — JavaScript interactions  

## How It Works
The project uses simple DOM manipulation and event listeners:

- `click`
- `mouseover`
- `mouseout`

Each event updates the box’s background color and text content.
